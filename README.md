## ⚙️ Instalación

### 1. Clonar repositorio

```bash
git clone https://github.com/oreterraC/sunod-server.git
cd sunod-server
```

### 2. Instalar dependencias

```bash
npm install
```

### 3. Configurar variables de entorno

Copia `.env.example` y cámbiale el nombre a `.env`, luego introduce tus valores 

### 4. Ejecutar proyecto

```bash
npm run dev
```

La aplicación estará disponible en:

```text
http://localhost:5000/
```

---

### 🔗 Dependencia del frontend

Este repositorio proporciona exclusivamente la API de Sunod.
Para utilizar la aplicación completa es necesario ejecutar también el proyecto `sunod-client`, disponible en `https://github.com/oreterraC/sunod-client`,
encargado de consumir los datos del servidor y mostrarlos mediante la interfaz de usuario.
El backend puede ejecutarse de forma independiente, pero no ofrece una interfaz visual propia.
